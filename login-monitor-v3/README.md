# Login Activity Monitor (v3)

Run:   node server.js   (or: npm start, or double-click start.bat)
Open:  http://localhost:3000
Admin: admin@example.com / Admin@123
Needs Node.js 22.13 or newer. node_modules is included (no npm install needed).
Reset all data: stop the server and delete data.db

Pages (12): Home, Register, Login, Dashboard, My Login History, Profile, Change Password,
Admin Dashboard, All Logs, Locked Accounts, IP Report, Manage Users.
