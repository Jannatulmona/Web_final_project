What it does

Account lockout

Five wrong passwords lock the account for 15 minutes, stopping brute-force guessing.

Full login history

Every attempt is logged with time, IP address, device and result.

IP blocking

Admins can block an IP, and an IP with 20 failures in 10 minutes is blocked automatically.

New-IP alerts

Users are warned when their account is used from an IP address they have not used before.

Risk score

Each user gets a 0-100 score from recent failures and unusual sign-ins.

Reports

Charts, filters and CSV export for the security administrator.

How a sign-in is checked

  1. Is the IP address blocked? If yes, reject.
  2. Is the account locked? If yes, reject and log it.
  3. Is the password correct (bcrypt)? If not, count the failure and lock after 5.
  4. If correct, reset the counter, log success and start a secure session.

Two roles

User

Dashboard, own login history, profile and password change.

Security admin

Logs, locked accounts, IP report, user management and statistics.
